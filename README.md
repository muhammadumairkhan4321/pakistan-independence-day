# 🇵🇰 Pakistan Independence Day – Interactive Web Experience

An interactive and visually engaging web experience created to celebrate **Pakistan Independence Day 🇵🇰**.

This project combines HTML, CSS, JavaScript, animations, visual effects, multimedia, and a lightweight Node.js server to create an engaging Independence Day experience.

---

## 🌟 Features

* 🇵🇰 Pakistan Independence Day themed interface
* ▶️ Interactive start screen
* 🎬 Animated Independence Day content
* ✨ Background particle effects
* 🇵🇰 Pakistan flag presentation
* 💚 Glowing visual effects
* 🎵 Background Independence Day music
* 🎉 "Happy Independence Day" final message
* 👨‍💻 Personalized creator section
* 🌐 Lightweight local Node.js server
* 📱 Designed as a web-based interactive experience

---

## 🛠️ Technologies Used

* **HTML5** – Web page structure
* **CSS3** – Styling, animations, and visual effects
* **JavaScript** – Interactivity and animations
* **Node.js** – Local development server
* **Google Fonts** – Montserrat font
* **HTML5 Audio** – Background music

## 📋 Requirements

To run this project locally, you need:

* Node.js installed on your computer
* A modern web browser such as Google Chrome, Microsoft Edge, or Firefox
* Internet connection for loading Google Fonts
* All project files and media assets in the same project folder

### Important

Make sure the following files are present:

```text
index.html
style.css
script.js
server.js
pakistan_flag.jpg
independence_music.mp3
```

The website uses the Pakistan flag image and Independence Day music as external project assets, so these files should not be removed or renamed.

## 🚀 How to Run the Project

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/pakistan-independence-day.git
```

Replace `YOUR-USERNAME` with your GitHub username.

### 2. Open the Project Folder

```bash
cd pakistan-independence-day
```

### 3. Start the Local Server

Run:

```bash
node server.js
```

You should see:

```text
🇵🇰 Pakistan Independence Day
--------------------------------
Website running at: http://localhost:3000
Press CTRL + C to stop the server.
```

### 4. Open the Website

Open your browser and visit:

```text
http://localhost:3000
```

The Pakistan Independence Day experience will start in your browser.

---

## 🖥️ How the Server Works

This project includes a lightweight Node.js HTTP server.

The server:

* Serves the `index.html` file
* Serves CSS and JavaScript files
* Serves images and audio files
* Handles different file types using MIME types
* Runs locally on port `3000`

The server is built using Node.js's built-in modules, so **no external npm packages are required**.
